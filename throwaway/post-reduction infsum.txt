t first: 
1/2/2/2 = 2^-3
1/2/2/2/2/2 = 2^-5
1/2/2/2/2/2/2/2 = 2^-7
...

S_n = 2^-3 + 2^-5 + 2^-7 + ... + 2^-n
2^-2 * S_n = 2^-5 + 2^-7 + 2^-9 + ... + 2^-(n+2)
as n->infinity
S_n(1-2^-2) = 2^-3
S_n = (2^-3)/(1-2^-2) = 1/6

h first:
1/2/2 = 2^-2
1/2/2/2/2 = 2^-4
1/2/2/2/2/2/2 = 2^-6
...

S_n = 2^-2 + 2^-4 + 2^-6 + ... + 2^-n
2^-2 * S_n = 2^-4 + 2^-6 + ... + 2^-(n+2)
as n->infinity
S_n(1-2^-2) = 2^-2
S_n = (2^-2)/(1-2^-2) = 1/3

thus infsum probability = 1/3 + 1/6 = 1/2
