### Single-Item Auctions

Good starting point is **Single-Item Auctions**

Seller with $1$ good
$n$ bidders

**Valuation**: Each bidder $i$ valuation $v_i$ equal to maximum value the bidder will pay

valuation is **private** to bidders and seller - private valuation

Utility model: "quasilinear utility"
utility of losing = $0$
utility of winning at price $p = v_i-p$
model bidders as acting to maximise their quasilinear utility

### Sealed-Bid Auctions

1. Each bidder submits a bid to the seller privately
2. Seller decides winner
3. Seller decides on a selling price

Choose highest bidder for step 2

#### 2nd price/Vickrey auction

Winner pays value of 2nd highest bid (~eBay)

Easy to analyse and easy to predict what will happen

**Claim 1**: In a 2nd price auction, every bidder has a dominant strategy: bid = $v_i$. This is bid is guaranteed to maximise i's utility no matter what other bidders bid.

**Proof**: fix $i$, $v_i$, and other bids $b$
**RTP**: $i$'s utility is maximised by bidding $v_i$

Let B = max $b_j$, $j$ != $i$ of $b$

2 cases:
1. $v_i$ < B, thus utility = 0
2. $v_i$ >= B, thus utility = $v_i-B$

In case 1:
$v_i < B$
max possible utility = 0
achieved by setting $b_i = v_i$

In case 2:
$v_i >= B$
max possible utility = $v_i-B$
achieved by setting $b_i$ = $b_i$

**Claim 2**: In a 2nd price auction, every truth-telling bidder gets non-negative utility

**Proof**: Selling price <= winner's bid

Therefore, Vickrey auction is awesome.

1. Dominant-strategy incentive compatible (DSIC) - Claim1 + Claim2
2. Maximises social surplus - If bidders bid truthfully, the action maximises the social surplus = value of winner aka highest valuation bidder wins $\sum_{i=1}^{n}{v_i\cdot x_i}$ where $x_i$ = 1 if $i$ won the auction and $x_i=0$ if $i$ lost the auction
3. Linear time auction

### Case Study: Sponsored search options

Tens of billions dollars a year generated by Google from these.

When you have a search query, you get 2 sets of results

1. organic search results
2. sponsored links

Every search query, an auction is run in real time.

More complex than single item auctions because:
- Multiple goods
- Not interchangeable, since goods are not the same

Goods - the $k$ "slots" on the results page

Bidders - advertisers who have bid on the current query

Note - not identical, higher is generally better

let $\alpha_j$ = probability that $j$th slot gets clicked on (Click through rate or CTR)

Higher $\alpha$ is better

**Assumptions**:
1. $\alpha_1 >= \alpha_2 >= ... >= \alpha_k$ 
2. $\alpha_j$ is independent of occupant
3. Bidder cares have a private valuation $v_i$ **per click**, hence derives value $v_i\cdot \alpha_j$ From slot $j$

Desiderata (~Vickrey)
1. DSIC auction
2. Maximises social surplus $\sum_{i=1}^{n}{v_i\cdot x_i}$ Where $x_i$ = CTR of slot $i$ gets assigned($0$ if no slot)
3. Poly time, ideally linear time

There is an option with all 3 properties for sponsored search options, but there isn't always one.

---

The reason why mechanism design problems seem hard is because you have to decide
- Who wins
- How much the winner has to pay

Whether or not a system can be "gamed" depends on both of these problems, you can get one right and the other wrong and have flaws.

First choose a winner, then choose a way to decide how much they pay aiming to achieve the 3 properties

1. DSIC
2. max surplus
3. poly time
